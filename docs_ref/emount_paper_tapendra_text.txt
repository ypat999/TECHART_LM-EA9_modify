8 Communication Protocol
The camera initiates the communication. The camera and the lens first make sure that the
UART lines are powered and the handshaking lines are responding during Link Establish-
ment phase. Secondly, the camera and the lens negotiate the communication speed during
speed negotiation phase. Third, the camera homes the focus and aperture, and the camera
configure lens to send update on BODY_POLL_LENS pulse during initialization phase.
Finally, the camera sends message to update focus and aperture after receiving the update
from the lens during regular messaging phase.
8.1 Link Establishment
Figure 5: Link Establishment
During link establishment, the camera and the lens make sure that they are ready to com-
municate.
• First, the camera pulls BODY_CS_LENS high and waits for about 2s before resetting.
If the LENS_CS_BODY goes high in that duration, the camera powers TX and waits
until RX goes high.
• The lens holds LENS_CS_BODY high until TX to goes high.
• Once TX goes high, that indicates that the camera is ready to talk so the lens powers
RX to indicate that it is ready to talk and pulls the LENS_CS_BODY low.
• RX being powered indicates that the lens is ready to talk, so the camera pulls the
BODY_CS_LENS low.
9

Now the camera can start to communicate. Now the handshaking line act normally, i.e.,
when you pulse BODY_CS_LENS the lens responds with LENS_CS_BODY pulse.
8.2 Speed Negotiation
After establishing the communication link, the camera and the lens negotiate the speed
change from 750K baud rate to 1500K baud rate. This phase is referred to as the speed
negotiation phase in this document. After this phase, the camera and the lens will commu-
nicate at 1500K baud rate. See full payload in Appendix.

communication and power should only be provided once the lens is detected, otherwise the
lens pads can make contact with powered pins. See full payload in Appendix.

All the states have enter actions. The actions are summarized below.
13.2.1 Action Idle enter
• End UART communication. Serial1.end().
• Turn all pins to high impedence. Set BODY_POLL_LENS, LENS_CS_BODY,
RX, TX, BODY_CS_LENS to input mode. (Lens Detect pin will always be IN-
PUT_PULLUP.)
• TurnofflogicVccandlenspwrusingthetransistor. (LENS_PWR_SWandLOGIC_VCC
will always be OUTPUT.)
13.2.2 Action Link Establishment enter
• Set TX as output and RX as input for initial handshaking.
22

• Set BODY_POLL_LENS and BODY_CS_LENS as output.
• Start by setting all pins controlled by the micro-controller as Low. That is, set
BODY_POLL_LENS, BODY_CS_LENS, TX, LOGIC_VCC_SW as low.
• Power logic Vcc. Set BODY_POLL_LENS to default High.
• Start the handshake by pulling BODY_CS_LENS high.
13.2.3 Action Speed Negotiation enter
• Set RX and TX pin for serial communication on serial1.
• Set the baud rate of 750K.
• Start the speed negotiation by sending 0x01 type message.
13.2.4 Action Initialization enter
• Send BODY_CS_LENS pulse to see if we get the ACK back from the lens. In our
implementation, we don’t actually check if we get the ACK back, we only send pulse
and have some delay.
• Change the baud rate to 1500K.
• Turn the Lens Pwr on.
• Start the Initialization by sending 0x0B type message.
13.2.5 Action Regular Messaging enter
• Enable Polling.
13.2.6 Action Shutdown enter
• Send 0x0A message to initiate shutdown sequence.
13.2.7 Action Off enter
• End UART communication. Serial1.end().
• Set TX, RX, BODY_POLL_LENS, BODY_CS_LENS pins to INPUT.
• Turn off Logic Vcc and Lens Pwr.
• Disable polling.
