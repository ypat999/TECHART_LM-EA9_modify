LM-EA9 本地刷写套件（flash_kit）
================================
仓库：https://github.com/ypat999/TECHART_LM-EA9_modify（整个工作目录已入库）

【原理】
升级程序 TECHART_Updater 先从 http://www.techart-logic.com/product/TECHART_LST.txt
拉取固件清单，再按清单里的 URL 下载 bin，经底座 USB(HID, VID 0483 / PID 575A) 写入环。
把该域名解析到本机、用本目录起 HTTP 服务，即可让升级程序刷入任意本地 bin。
无签名校验、无版本回退校验（已逆向确认）。STM32 常驻 bootloader，刷坏可重刷救回。

【重要：HTTP 根目录 = flash_kit 本身】
清单 URL 里带 /product/ 前缀，所以 serve.bat 必须以 flash_kit 为根
（flash_kit\product\... 才是 http://.../product/...）。serve.bat 已按此配置。

【目录】
product\TECHART_LST.txt            当前生效的固件清单（当前 = P23, VER 3.5.0）
product\firmware\LM-EA9\*.bin|txt  全部候选固件及说明文件
lsts\TECHART_LST_P*.txt            每个 patch 一份清单（切换用，只含一行）
lsts\TECHART_LST_ORIG.txt          官方 v1.8.0（回滚）
lsts\TECHART_LST_V16.txt           官方 v1.6.0（§8.3 对比度判决实验用，本地已镜像）
serve.bat                          启动本地 HTTP（端口 80，需 python）
hosts_add.bat / hosts_remove.bat   添加/移除 hosts 劫持（需管理员）

【刷写步骤】
0. 前置检查（关键）：系统若配有 HTTP 代理（公司代理 / Clash / v2rayN 等），
   .NET HttpWebRequest 会走代理，代理会去解析真实域名 ⇒ hosts 劫持失效，
   结果就是"你以为在刷 P1，其实官方清单被拉下来了"。
   处理：刷写期间临时关闭系统代理（设置→网络→代理，或代理软件切"系统代理 关"），
   并在下一步用本机解析验证。winhttp 已是 Direct access 不代表 .NET 无代理。
1. 管理员运行 hosts_add.bat（写入 127.0.0.1 www.techart-logic.com + 刷 DNS 缓存）
2. 关闭占用 80 端口的程序（IIS / Skype / 其他 web server）
3. 运行 serve.bat，窗口保持开着（这里能看到每一条 GET 请求 = 唯一可信的判据）
4. 验证劫持+路径都对（★用 curl，别用浏览器——浏览器会缓存这个 txt）：
   curl.exe http://www.techart-logic.com/product/TECHART_LST.txt
   ⇒ 应显示你当前的清单（当前默认那行 VER 3.5.0 = P23），且 serve.bat 窗口出现 GET 日志。
   另需确认 hosts 条目真的独立成行：
     ping -n 1 www.techart-logic.com        （必须显示 127.0.0.1）
     type %WINDIR%\System32\drivers\etc\hosts | findstr techart
   若解析成公网 IP ⇒ 跑 hosts_fix.bat（管理员）修复粘连，再 flushdns。
   若 curl 显示一堆官方产品行 ⇒ 系统代理没关。
5. 想换 patch：把 lsts\TECHART_LST_XX.txt 复制覆盖到 product\TECHART_LST.txt
   （覆盖后重复第 4 步确认页面内容已变）
   cmd 语法（把 P1 换成 P2a/P2b/P3/P4/P5/ORIG/V16 即可）：
     copy /y "d:\work\techart\flash_kit\lsts\TECHART_LST_P1.txt" "d:\work\techart\flash_kit\product\TECHART_LST.txt"
     type  "d:\work\techart\flash_kit\product\TECHART_LST.txt"
   查 80 端口占用 / 起服务 / 启动升级程序（cmd）：
     netstat -ano | findstr ":80 "
     python -m http.server 80
     start "" "d:\work\techart\TECHART_Updater(USB-WIN).exe"
6. 环装到底座 → 打开 TECHART_Updater → 列表里应只有一行（你选的那个 VER）→ 升级
   ★清单只放一行是故意的：避免在下拉里点错版本。
7. 刷完先验证落地（清单回显的版本号不算证据）：机身镜头信息/EXIF 看镜头名是否
   变成 patch 名（如 TECHART LM-EA9-P7），升级程序读回设备版本是否抬高；再试机测绿框
8. 全部测完：管理员运行 hosts_remove.bat 恢复 hosts（备份在 hosts.bak）

【失败与回滚】
- 升级中途报错/断电：重跑一次即可，bootloader 常驻不会变砖。
- 想回官方：lsts\TECHART_LST_ORIG.txt 覆盖生效清单 → 刷 VER 1.8.0。
- 某 patch 刷进去行为更糟：直接刷 ORIG 回滚，再换下一个 patch。
