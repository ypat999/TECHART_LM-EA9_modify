【1. 核心成果(换机后必须知道的)】
  a. checksum 规则: cksum(LE16) = sum(frame[1..len-4]) & 0xFFFF。
     即帧内从 len 低字节到 body 末尾全部字节之和(排除 0xF0 头、cksum 自身 2 字节、尾 0x55)。
     存储位置: frame[len-3..len-2]。
  b. 帧格式: 0xF0 + len(LE16=整帧长) + class + seq + type + body + cksum(LE16) + 0x55。
  c. 机身不校验 checksum(TechArt 官方改 body 后照抄模板 ck 也正常工作) -> 但我们的 patch 一律写回正确 ck。
  d. 固件为 STM32 常驻 bootloader, 刷坏可救(重刷任意固件即可), 无签名/版本校验。
  e. 关键帧(全在 v1.8.0, 文件 20172 字节):
       init07 @0x4A38(len43, body@0x4A3E)  = 驱动/AF区域声明帧  <- 本轮主战场
       norm05 @0x4B7C(len105, body@0x4B82) = 位置/距离/光圈主帧
       init01 @0x4A0C(len41, body@0x4A12)  = 型号标定档案
       init3F @0x4C08(len74, body@0x4C0E)  = 镜头名(探针改名处)
       init08 @0x4A88(len210) = 马达标定(高危, 勿整帧换, 已被 P5 证伪)
  f. init07 是"活帧"(Y2 实证): 直接控制机身相位 AF 区域框大小与合焦判定松紧。
     拆解结论: @0=合焦判定/反差确认位(01跳过确认直接绿但虚, 02严格确认M40永不绿);
               @1=反差收敛模式位(01=反差拉风箱收敛真合焦但慢, 仅中心);
               @2=安全提速正信号(08->60, Z1实证: 框同官方/边缘略好/快);
               @5/@7=非关键安全位; @9@10=量程对(改大会破坏边缘, 负效果)。

【3. 刷写套件用法(flash_kit, 换机后全新环境也可用)】
  a. 关闭系统代理(Clash/v2rayN 切"系统代理:关"), 否则 hosts 劫持被绕开。
  b. 管理员运行 flash_kit\hosts_add.bat  (劫持 www.techart-logic.com -> 127.0.0.1)
  c. 运行 flash_kit\serve.bat            (本地 HTTP 服务, 窗口保持开着)
  d. cmd: copy /y 想刷的lsts\TECHART_LST_XXX.txt product\TECHART_LST.txt
  e. 验证: ping www.techart-logic.com 必须回 127.0.0.1;
           curl.exe http://www.techart-logic.com/product/TECHART_LST.txt 必须只显示一行且含目标bin。
  f. 运行 TECHART_Updater(USB-WIN).exe, 列表应只有该行, 点升级。
  g. 落地确认: 机身/升级程序读回对应 VER 与镜头名(TECHART LM-EA9-Vn 等)。
  h. 换下一个: 只需重复 d+e+f, hosts 与服务不用动。
  i. 收工: 管理员运行 flash_kit\hosts_remove.bat。
  j. 回滚: 刷 lsts\TECHART_LST_ORIG.txt(=官方 1.8.0)。

【4. 常见坑】
  - 升级程序若显示一堆官方产品行 => 系统代理没关。
  - ping 不是 127.0.0.1 => hosts 没生效, 管理员跑 hosts_fix.bat。
  - 落地后镜头名/VER 读回不对 => 可能是缓存, 重新插拔/重开升级程序。
  - 观察前 10 次 AF 有无异响/撞限位, 尤其测 init08 类 patch(P5 已弃用)。

【5. 已实测结论速查(别重复劳动)】
  35mm(FD): P23(init01 @5=80 + @7=00) 显著改善。35mm 上 @5 越高越好, 已夹逼到 80。
  40mm:     init01 @5 曲线以 80 为峰, 两侧单调下降(X12@A0/X13@C0/X14@40 均更差)。
            @6 平坡(08~18), @7 平坦(00≈7E)。P23/X10/X15 一簇"无明显改善"。
            Z1(@2=60) 框同官方/边缘略好/速度快 - 安全提速件, 可叠加任何档。
            Z5(@1=01) 反差收敛真合焦仅中心, 慢, 边缘不行。
            X1/X3/X4(照抄Sigma/native的@4/@2@3/init08[13]) => 直接丧失对焦能力(死因)。
            init08 整帧换 native(Y2 假合焦) / init08[13]=E1(X4) / [17]=15(X11) 均无改善。
            F 字段(P1等)在 35mm 上无效, X8(M40 上)低优先。
  版本考古: 7 版无差异, 跨版本字段与主症状无关。norm06@9 待 v1.6 判决实验(低优先)。
  A7R3A: 无纯对比度开关, 静态表之外无"对比度开关"字段。
